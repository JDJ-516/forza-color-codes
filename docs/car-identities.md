# Current-car identification and tuning prefills

Forza sends a numeric CarOrdinal, not a year, make or model. `car-identities.js`
resolves it against `public/car-identities.json`: 551 FH6-specific merged IDs.

Source: [ClickClickMedia/Forza-6-telemetry, pinned commit
523e8ba188d0f7c0a5540139174db286198e851c](https://github.com/ClickClickMedia/Forza-6-telemetry/tree/523e8ba188d0f7c0a5540139174db286198e851c/app/data).
The source's 550-entry `fh6_car_catalog.json` uses game manifest IDs and names
prettified from car-folder codes; its five community-confirmed entries in
`car_ordinals.json` take precedence. The upstream source describes the latter as
confirmed by contributors; this is not independent game validation by this app.
The merged file records SHA-256 hashes of both original JSON files. Names may
have imperfect formatting, and new/unmatched IDs remain unknown. No mapping is
borrowed from FH4/FH5/Motorsport, and spreadsheet names are not matched by guess.
The source's MIT license is included as `public/car-catalogue-LICENSE.txt` in both
Windows packages. Copyright © 2026 ClickClickMedia.

The Tune Calculator only identifies a currently driven car from a fresh,
validated, active frame. Inactive, stale, rejected or disconnected data never
claims a current car. An offline setup HTML guide is linked when disconnected.

Automatic inputs:
- Car labels across Drag/Track/Drift and benchmark context; reported class/PI in
  benchmark context and drivetrain in Drag.
- Track shift RPM and Drift target RPM start at the reported engine RPM limit.
  These are starting values, not recommended optimal shifts.
- Drag manual power and torque remain user inputs. A dedicated real-run capture
  fills the separate observed engine outputs, torque-peak RPM and actual median
  upshift RPM. Its explicit copy button can transfer measured power/torque into
  the model. See [drag capture](drag-capture.md) for eligibility and stop behavior.


Mass, tires, exact gearing, total gear count, friction, drivetrain losses, weight
distribution, launch-control mode and other unreported inputs remain manual.
The feed does not contain the complete tune or a leaderboard-quality guarantee.
A reported RPM limit is not the best shift point, and the highest observed gear
is not proof of the gearbox's total gear count.

Manual edits and explicitly loaded saved builds override prefills. On a car/build-key change (ordinal, PI,
drivetrain or engine limit), the app retains that car's worksheet in a bounded
20-profile memory cache, clears car-specific inputs/old curve evidence, restores
any manual profile for the new key, and applies new telemetry values. Strip
selection/distance remain unchanged. Autogenerated values are recomputed rather
than restored. This cache lasts only until the page closes/reloads; saved builds
remain the persistent option. Changes to a build that leave every key field
unchanged cannot be detected automatically.

The receiver also clears capture/observed-engine evidence on detected build
changes. A fresh dedicated drag capture resets its own measurements and automatic RPM targets; manual overrides remain. General capture reset remains separate. Stopping the server clears
all live evidence. Manual worksheets are retained when the connection drops,
while the current-car identity is cleared and the setup link becomes available.
