← Forza-ingenium Telemetry

Connect your game.

Run Forza-ingenium on the same PC as the game. Start the app using its desktop shortcut or Start launcher.

  1. Open Settings in the game.
  2. Select HUD/Display.
  3. Open Telemetry.
  4. Set Data Output to ON.
  5. Set IP to 127.0.0.1.
  6. Set Port to 5300.

Enter driving. The Telemetry connection text turns green when fresh readings decode successfully. Tune Calculator then identifies your car and fills supported inputs.

If no packets arrive, check that the app is running and the IP/port match. If packets arrive but are invalid, the Telemetry tab reports the failed field. No router forwarding is needed for this same-PC setup.
